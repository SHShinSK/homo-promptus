# Homo Delegans 선언 (풍자 각본)

우리는 **생각까지 맡기는** 편의를, 부끄럽게가 아니라 **익숙하게** 만들었다.

## 풍자의 대상

- 한 줄 지시: *“알아서 해줘”*
- 결과 미확인: *“잘 됐겠지”*
- Auto Context™, Skip Thinking, Approve All

## 풍자가 아닌 것

- 사용자의 지능·가치
- AI 도구 자체

## 카피 원칙

- **행동·UX·습관**만 과장한다.
- “멍청하다” 대신 “편하다”, “빠르다”, “AI가 알아서”를 쓴다.

## 한 줄

> 생각은 선택이었는데, 이제 기본값이 위임이다.
