# Homo Promptus 선언

우리는 AI 시대에 **최소한의 생각**을 포기하지 않는다.

## 우리가 남기는 것

1. **의도** — 무엇을 원하는지 한 문장으로 말한다.
2. **맥락** — 배경·제약·이미 시도한 것을 적는다.
3. **검증** — 결과를 읽고, 불확실한 부분을 표시한다.

## 우리가 말하지 않는 것

- “AI가 다 알아서 해줬으니 좋겠다”를 진지한 목표로 삼지 않는다.
- Promptus가 우월하다고 말하지 않는다. **조금만 더 남기는 선택**일 뿐이다.

## 한 줄

> 프롬프트는 위임이 아니라, 생각의 잔여물이다.
